# 生物课模拟器

一个在群聊和私聊里玩的 AstrBot 插件。从 50 分起步，上课答题、默写、写作业，看看能不能把生物成绩提到 100 分。每天还可以抽一句自己的生物课金句。

## 安装

需要 **AstrBot 4.9.2 或更新版本**。插件使用 Python 标准库，无需安装额外依赖或配置模型。

### 从 WebUI 安装

1. 打开 AstrBot WebUI 的「插件 → 已安装」，点击「安装插件（+）」。
2. 选择「从链接安装」，粘贴以下地址。

   ```text
   https://github.com/stalyx-meow/astrbot_plugin_biology_lesson_simulator
   ```

3. 安装后确认「生物课模拟器」已启用，在聊天中发送 `/生物课` 查看帮助。

### 手动安装

在 AstrBot 根目录运行以下命令，然后重启 AstrBot。目录已存在时，可在 WebUI 更新插件，或在保留存档和配置的情况下替换插件目录中的源码。

```bash
git clone https://github.com/stalyx-meow/astrbot_plugin_biology_lesson_simulator.git \
  data/plugins/astrbot_plugin_biology_lesson_simulator
```

安装入口因 AstrBot 版本而异，详见 [AstrBot 插件安装文档](https://docs.astrbot.app/use/plugin.html)。

## 第一天怎么玩

1. 发 `/生物课 状态` 查看成绩、精力和手上的作业。默认初次进入会收到一份每日作业。
2. 发 `/生物课 上课`，然后选 `/生物课 答题` 或 `/生物课 睡觉`。答错时继续发答题指令，下课后也可以补答。
3. 发 `/生物课 默写`，过关后会加分并拿到一份额外作业。手头的作业可用 `/生物课 写作业` 完成，每次处理一份。
4. 发 `/每日金句` 抽取今日金句。当天再次查询会显示同一句。

## 指令

下面使用 AstrBot 的默认唤醒前缀 `/`。如果机器人用了其他前缀，请替换开头的 `/`。

| 指令 | 用途 |
| --- | --- |
| `/生物课` | 查看帮助，也可以用 `/生物课模拟器` |
| `/生物课 状态` | 查看成绩、精力、当日课时、作业、试卷和效果 |
| `/生物课 上课` | 开始一节课 |
| `/生物课 答题` | 回答课堂问题或重答 |
| `/生物课 睡觉` | 用本节课恢复精力 |
| `/生物课 默写` | 参加默写或重默 |
| `/生物课 签订协议` | 查看永久免默写协议 |
| `/生物课 确认签约` | 确认签订协议 |
| `/生物课 偷试卷` | 签约后尝试获得一张试卷 |
| `/生物课 写作业` | 独立完成一份作业并加分 |
| `/生物课 抄作业` | 消耗较少精力完成一份作业，有概率触发「同」 |
| `/每日金句` | 抽取当天的个人金句，也可以用 `/生物课 金句` |

## 游戏规则

每天按北京时间零点换日，精力在玩家当天第一次使用游戏功能时恢复到上限。成绩最高 100 分。下表为默认设置。

| 行动 | 精力 | 结果 |
| --- | ---: | --- |
| 课堂答题 | −10 | 65% 概率答对，成绩 +3 |
| 课堂睡觉 | +25 | 恢复至多 25 点精力，受精力上限限制 |
| 默写 | −15 | 70% 概率过关，成绩 +4，并获得 1 份奖励作业 |
| 偷试卷 | −5 | 60% 概率拿到 1 张试卷，库存可在「状态」查看 |
| 写作业 | −20 | 完成 1 份作业，成绩 +3 |
| 抄作业 | −5 | 完成 1 份作业，30% 概率触发「同」 |

- **课堂**：默认每天最多开 3 节，每节按真实时间持续 45 分钟，同时只能上一节。答对或睡觉后，本节课堂活动完成。答错后须先补答，待补答状态可以跨天。
- **默写与协议**：每天最多过关一次，跨天补过关计入过关当天。有待重默时，先过关才能签约。签约永久有效，此后免默写并失去今后的默写奖励作业。默认从签约当天起连续 45 天获得「红利」，每天加 1 分，离线期间应得的分数会补算。
- **作业**：当天首次结算时，手上所有作业已清空才发每日作业，签约玩家同样领取。有积压就跳过当日发放，清空后下个游戏日再发。完成时先扣每日作业，再扣默写奖励作业。「同」默认覆盖触发当天和接下来的 4 天，期间只能自己写。

## 调整参数

在 WebUI 找到「生物课模拟器」，点击齿轮修改配置，保存后重载插件。概率填写 0～100 的百分数，例如 `65` 表示 65%，`12.5` 表示 12.5%。

| 类别 | 可调整的参数 |
| --- | --- |
| 基础 | 初始成绩默认 50，精力上限及每日恢复值默认 100 |
| 课堂 | 每日节数、每节时长、答题消耗、答对概率、答对加分、睡觉恢复量 |
| 默写 | 每次消耗、过关概率、过关加分、奖励作业份数 |
| 协议 | 「红利」天数、每日加分、偷试卷消耗、成功概率 |
| 作业 | 每日发放量、独立完成消耗及加分、抄作业消耗、「同」的触发概率及持续天数 |
| 金句 | 自定义列表，每项一句，留空时使用内置金句 |

把每日节数设为 `0` 可暂停开课。把每日作业或默写奖励的份数设为 `0` 可关闭对应发放。把「同」的触发概率设为 `0` 可关闭该效果。答对或默写过关概率设为 `0` 时，对应行动会始终失败。

初始成绩仅对新玩家生效。课长用于新开的课，效果参数用于之后触发的效果。已发放的作业与当天已抽中的金句会保留。精力上限降低后会压低当前精力，提高后将在下次每日刷新补到新上限。

## 存档和排查

- **存档位置**：`data/plugin_data/astrbot_plugin_biology_lesson_simulator/players.sqlite3`。同一 AstrBot 平台实例中的同一账号，在群聊和私聊共用进度。
- **指令无响应**：确认插件已启用、当前聊天使用的 AstrBot 配置允许此插件，并使用正确的唤醒前缀。可以用 `/help` 查看已启用的指令。
- **配置未生效**：确认修改的是当前运行实例的插件设置，保存后重载，再用 `/生物课 状态` 检查。
